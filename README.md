# EasySend

[官方网站](https://fishxin.github.io/easysend-website/) · [下载安装包](https://github.com/FishXIN/easysend-website/releases) · [反馈问题](https://github.com/FishXIN/easysend-website/issues)

EasySend 用于在设备之间传送文件、文本与剪贴板。此公开仓库只包含静态官网、许可声明和公开 Release 安装包；应用源码保持私有。

当前提供开发预览版：macOS / Windows / Android 为 **1.18.6 构建 72**，Linux 暂为 **1.18.4 构建 66**。安装包名称、SHA-256、构建来源和各平台验证边界见对应 Release。没有可安装的 iPhone / iPad 包。

同一局域网可发现附近设备。长期设备配对与自托管跨网服务仍处于开发预览阶段，没有默认公共服务，跨网直连、完整费用策略与任务恢复仍在开发，真实跨网尚未验收。

## 网站

HTML、CSS 和少量 JavaScript，直接由 GitHub Pages 发布。不包含应用源码、密钥、运行身份或在线文件上传服务；不使用分析追踪脚本。
